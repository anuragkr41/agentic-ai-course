How this course works

Each module: read the anchor text → watch the curated videos → step through the interactive walkthroughs → answer 10 MCQs + 2–3 scenarios → aim for ≥80% on every test. Modules are open in any order — but a StratifyX completion certificate is awarded only after every required module test is passed. Progress is saved locally in this browser (no account needed); best score per module is kept.

📺 About the videos

Each module embeds curated YouTube videos as click-to-watch thumbnails — click any thumbnail to open the video on YouTube in a new tab. This pattern works universally (no iframe embedding restrictions, no local server needed). Page stays fast; videos play wherever YouTube plays.
