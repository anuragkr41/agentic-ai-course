1. What is an LLM?

LLM stands for Large Language Model. The one-sentence version: an LLM is a program that takes text in and produces text out. Examples: ChatGPT, Claude, Gemini, Llama. They've been trained on enormous amounts of text from the internet, books, and code, and they've learned to predict what text should come next given any input.

Three things worth knowing now:

  • LLMs are stateless by default. They don't remember earlier conversations unless you re-send the history with each request. Memory is something you bolt on.
  • LLMs hallucinate. They produce plausible-sounding text that may be factually wrong. A huge part of agentic AI is engineering systems that force the LLM to ground its answers in real data (covered deeply in Modules 5 and 7).
  • LLMs are called via APIs. The model itself runs on someone else's servers (OpenAI, Anthropic, Google). Your program sends a request, pays per use, and gets a response. Which leads us to…

2. What is an API?

API stands for Application Programming Interface. Don't let the name throw you. The one-sentence version: an API is a way for one program to ask another program for something over the internet.

Whenever your app needs to do something it can't do alone — call an LLM, look up a stock price, send a Slack message, query a database — it calls an API.

In agentic AI, almost every "tool" your agent uses is just an API call wrapped in a function. When Module 8 talks about "MCP servers exposing tools," it means: a standardized way to wire up these API calls so any agent can use them.

3. What is JSON?

JSON stands for JavaScript Object Notation. The one-sentence version: JSON is a text format for structured data — keys and values, like a dictionary.

Here's the same person described in plain text and in JSON:

Plain text: "Anurag is a founder. His tags are pm, founder, and engineer."

JSON:

{
  "name": "Anurag",
  "role": "founder",
  "tags": ["pm", "founder", "engineer"]
}

Three things matter for this course:

  • API requests and responses are JSON. When an agent calls a tool, what flies across the wire is JSON in, JSON out.
  • "Structured output" means forcing the LLM to produce valid JSON (e.g. {"refund_amount": 50.00, "reason": "shipping damage"}) instead of free-form prose. This is huge for reliability — covered in Module 3.
  • JSON has 6 value types: string ("hello"), number (42), boolean (true/false), null, list ([…]), and object ({…}). That's it.

4. What is a database?

A database is a structured place to store and retrieve data. Two flavors come up repeatedly:

  • Relational DB (SQL): data stored in tables with columns and rows, like spreadsheets that can reference each other. Queried with SQL. Module 12 builds a Text-to-SQL agent.
  • Vector DB: stores embeddings — numeric fingerprints of text that let you search by meaning rather than exact words. ("Find docs about refund policy" matches a doc that says "returns and reimbursements".) Modules 3, 5, and 7 use these.

You'll also meet knowledge graphs (Modules 6 and 7) — data stored as nodes (entities like People, Companies, Documents) connected by relationships (works-at, mentioned-in). Think LinkedIn under the hood.

5. How to read a Python snippet

You won't write Python — but every module shows short Python snippets to illustrate concepts. The good news: Python reads close to English. Here's everything you need to follow along.

The 6 patterns you'll see again and again

# 1. A comment — Python ignores everything after #
# 2. Assignment: name = value
prompt = "Summarize this contract"

# 3. Function call: function_name(arguments)
response = llm.invoke(prompt)

# 4. Method call: object.method(arguments)
text = response.content.strip()

# 5. A list (square brackets) and a dict (curly braces)
docs = ["doc1.pdf", "doc2.pdf"]
config = {"model": "claude-opus-4-7", "temperature": 0.2}

# 6. if / for — control flow
for doc in docs:
    if doc.endswith(".pdf"):
        process(doc)

When you see something like:

from langchain_anthropic import ChatAnthropic
llm = ChatAnthropic(model="claude-opus-4-7")
result = llm.invoke("What is agentic AI?")
print(result.content)

Read it as: "Pull the ChatAnthropic tool out of the LangChain library. Make an LLM client using the Opus model. Ask it 'What is agentic AI?'. Print whatever it says back." That's the entire mental model.

Survival rule

If you don't understand a line in a snippet, ask: what does this line accomplish? — not what does this exact syntax mean? The goal is reading comprehension, not authorship.

6. Glossary of recurring terms

TermOne-line meaning
LLMText-in, text-out model (Claude, GPT, Gemini).
PromptThe text you send to the LLM.
TokenThe unit LLMs charge by — roughly a word fragment. ~4 characters.
Context windowHow much text the LLM can read at once. Bigger = more expensive.
APIOne program asks another for something over the internet.
JSONText format for structured data — keys, values, lists.
SchemaThe shape a piece of data must take (e.g. "must have a name and an email").
AgentA program that uses an LLM + tools to pursue a goal autonomously.
ToolA function the agent can call (e.g. send_email, query_db).
RAGRetrieval-Augmented Generation. Find relevant docs → feed them to the LLM → get grounded answer.
EmbeddingA numeric fingerprint of a piece of text. Two similar texts have similar embeddings.
Vector DBA database that searches by embedding similarity (meaning), not exact text match.
HITLHuman-In-The-Loop. The system pauses for a human to approve before doing something risky.
HallucinationWhen the LLM produces plausible-sounding but false output.
GroundednessWhether the LLM's answer is actually supported by the source documents you gave it.
GuardrailsRules that block dangerous inputs or outputs (e.g. "never reveal secrets," "never send to an external email").
